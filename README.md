# SaadMan Saif — Deep Ancestry Discovery Platform

A deep ancestry investigation and visualization system centered on **SaadMan Saif** and the **Talukder** family lineage, tracing back through British colonial Bengal using genealogy databases, archival records, and historical research.

## Live Site

🔗 **[https://s-a-a-s.github.io/SaaS/](https://s-a-a-s.github.io/SaaS/)**

## What This Is

This is NOT a generic family tree website. This is a deep ancestry investigation that asks:

> **How far back can we trace the lineage of SaadMan Saif?**

Starting with 6 known generations of the Talukder family, the platform researches legitimate public sources to extend the ancestral line as far back as evidence allows.

## Features

- **Interactive Family Graph** — React Flow + ELK.js powered ancestral visualization
- **Cinematic Journey Through Time** — Remotion-powered motion video
- **Historical Timeline** — 233+ years of family and world history
- **Source Explorer** — 21+ genealogy sources analyzed
- **Research Frontier** — Visualizes where further research may yield results
- **Confidence Scoring** — Multi-signal weighted evidence scoring
- **Ancestral Depth Visualization** — Watch the tree expand backward through time
- **Premium Design** — AMOLED black + archival gold glassmorphism aesthetic

## Tech Stack

- **Framework:** Next.js 16 + React 19 + TypeScript
- **Visualization:** React Flow + ELK.js
- **Motion:** Remotion + Framer Motion
- **Styling:** Tailwind CSS 4
- **State:** Zustand
- **Charts:** Recharts
- **Icons:** Lucide React
